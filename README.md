# Robots 2D

A small Python learning project for exploring the mathematics of robotics while working through *Modern Robotics* by Kevin M. Lynch and Frank C. Park.

The project uses the [`spatialmath-python`](https://github.com/bdaiinstitute/spatialmath-python) package for transformations and spatial mathematics, and focuses on implementing simple 2D robot arms and their kinematics.

## Learning Goals

The main goals of this project are to:

* Learn and implement fundamental robotics mathematics.
* Work through concepts from *Modern Robotics*.
* Understand frames, joints, links, and transformations.
* Implement forward kinematics for simple robot arms.
* Experiment with different robot configurations.

## Reproducibility

The project was developed with:

* **Python 3.10.12**
* Dependencies listed in [`requirements.txt`](requirements.txt)

## Project Status

This is a **learning project** and is primarily intended for experimentation and studying robotics concepts. The implementation may change as new concepts from *Modern Robotics* are explored.
